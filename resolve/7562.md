- 시간 : 1

### 문제
체스판 위에 한 나이트가 놓여져 있다. 나이트가 한 번에 이동할 수 있는 칸은 아래 그림에 나와있다. 나이트가 이동하려고 하는 칸이 주어진다. 나이트는 몇 번 움직이면 이 칸으로 이동할 수 있을까?

![](https://www.acmicpc.net/upload/images/knight.png)
### 입력
입력의 첫째 줄에는 테스트 케이스의 개수가 주어진다.

각 테스트 케이스는 세 줄로 이루어져 있다. 첫째 줄에는 체스판의 한 변의 길이 l(4 ≤ l ≤ 300)이 주어진다. 체스판의 크기는 l × l이다. 체스판의 각 칸은 두 수의 쌍 {0, ..., l-1} × {0, ..., l-1}로 나타낼 수 있다. 둘째 줄과 셋째 줄에는 나이트가 현재 있는 칸, 나이트가 이동하려고 하는 칸이 주어진다.
### 출력
각 테스트 케이스마다 나이트가 최소 몇 번만에 이동할 수 있는지 출력한다.

- My solution
```python
from collections import deque
T = int(input())

direct_list = [(2,-1),(2,1),(1,2),(-1,2),(-2,1),(-2,-1),(-1,-2),(1,-2)]

def bfs(N,cur,target):
    graph = [[0]*N for _ in range(N)]
    queue = deque()
    queue.append(cur)
    while queue:
        q = queue.popleft()
        if q == target:
            return graph[q[0]][q[1]]
        for d in direct_list:
            x = q[0] + d[0]
            y = q[1] + d[1]
            if x < 0 or x >= N or y < 0 or y >= N:
                continue
            if graph[x][y] == 0:
                graph[x][y] = graph[q[0]][q[1]] + 1
                queue.append((x,y))
    return 0
            

for _ in range(T):
    I = int(input())
    cur = tuple(map(int, input().split()))
    target = tuple(map(int, input().split()))
    print(bfs(I,cur,target))
```
